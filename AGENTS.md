- One code cell per numerical feature: calls helper `plot_distribution(col)` then `print_interpretation(...)`.
- **1×3 graph** per feature: [Histogram | Density plot | horizontal Boxplot].

  - Mean (crimson dashed) and median (darkgreen dashed) vertical lines on histogram AND density plot.
  - Skewness annotated on the histogram (e.g. "Skewness: 0.09 (Symmetric)").
- Shape rule: |skew| < 0.5 → **Symmetric**; skew > 0.5 → Right-Skewed; skew < -0.5 → Left-Skewed.

- Interpretation printed after each plot: Shape (with skewness value), Mean, Median + difference,
